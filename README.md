# 장현서 Digital Portfolio V4

이번 버전은 요청한 수정사항에 맞춰 구성했습니다.

- HOME: 기존 느낌을 유지하면서 원형 오브젝트가 천천히 움직이는 생동감 추가
- ABOUT: 소개 + 강점 중심으로 구성하고 GROWTH는 작은 바로가기 요약으로 축소
- CAREER: 여러 학습지를 따로 카드로 나누기보다 하나의 PDF 기록물처럼 보이는 리더 구조
  - 검색
  - PDF 업데이트 버튼
  - 목차/페이지 구조
  - 업로드한 PDF는 브라우저에서 바로 미리보기
- ACTIVITIES: 교과/동아리/SKILLS의 상세 구조는 유지하면서 그 전에 3개 활동을 한눈에 보는 요약판 추가
- PROJECTS: 프로젝트 목록 중심의 간결한 포트폴리오 구조로 전면 변경
- GROWTH: 프로그래밍 경험을 연표 형태로 정리

## 실행
VS Code에서 이 폴더를 연 후 `index.html`을 Live Server로 실행하세요.

## CAREER의 실제 PDF 연결
`script.js`의 예시 페이지 대신 실제 PDF를 연결하거나, 화면의 PDF 업데이트 버튼으로 브라우저에서 임시 미리보기를 할 수 있습니다.
영구적으로 파일을 저장하는 업로드 기능은 서버/GitHub 등의 저장 기능을 연결해야 합니다.
