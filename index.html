01 / IoT

현관 조명 시스템

mmWave 센서와 Arduino를 이용한 자동 조명 제어 프로젝트입니다. 센서의 노이즈 문제를 신호 필터링으로 해결하며 하드웨어 센서 데이터 처리와 예외 관리의 중요성을 배웠습니다.

[배운 점] 센서에서 들어오는 데이터를 그대로 사용하는 것이 아니라, 상황에 맞게 처리하고 예외를 고려하는 것이 중요하다는 것을 배웠습니다.

↗
02 / C

해밍 코드 오류 검출

1차원 배열과 패리티 비트를 이용한 오류 검출 프로그램입니다. 비트 연산 과정을 직접 정리하며 데이터 무결성 검증의 원리를 이해하고 C언어 조건문 활용 능력을 키웠습니다.

[배운 점] 작은 데이터의 오류도 찾아내기 위해서는 논리적인 규칙을 세우고 단계적으로 확인하는 과정이 중요하다는 것을 배웠습니다.
